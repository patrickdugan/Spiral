# paper/

Documents from three programs share this folder. Which is which:

## Where the Capital Bound Moves (technical review, October 21, 2026)

- `tex/main.tex` — the paper; `tex/main.pdf` is its compiled form.
- `tex/grid.tex` — every number in the liquidity-duration grid, its accounting
  variants, the failed-events table, and the multiparty-channel tables of the
  BIP 448 section. Generated by `model/grid.ts`; never
  edited by hand.
- `tex/review_sensitivity.tex` is generated from the 96-run post hoc sensitivity record by `audit/peer_review/render_sensitivity.py`.
- `peer_review_changes.md` records the critique, corrections and questions for reviewers.
- `designed_topology_note.tex` preserves the exploratory topology appendix outside the reviewed paper; no capital result depends on it.
- `tex/references.bib` — its bibliography.
- `tex/fig_*.tex` — the TikZ figures, one file each; `fig_gain` and `fig_walks`
  plot data that `model/grid.ts` writes into `grid.tex`.
- `where_the_capital_bound_moves.md` — the superseded working draft, kept as it
  was.

Build from the repository root. The current PDF uses XeLaTeX through `latexmk`, with `natbib`, `booktabs`, `mathpazo`, TikZ and PGFPlots. The baseline PDF at `6a9df36` used Tectonic 0.17.

```bash
node --experimental-strip-types model/grid.ts > paper/tex/grid.tex
python audit/peer_review/render_sensitivity.py
latexmk -cd -xelatex -interaction=nonstopmode -halt-on-error paper/tex/main.tex
```

The complete sensitivity campaign can be rerun with:

```bash
node --experimental-strip-types audit/peer_review/model_sensitivity.ts > audit/peer_review/model_sensitivity.json
```

The [review audit](../audit/peer_review/README.md) separates archived evidence, newly executed model checks and the unexecuted implementation experiments. The Ark grid currently uses one 4032-block lifetime and omits idle fronting reserve. Its oracle comparisons match service within that model; the trailing server forecast is a post hoc diagnostic when it reports failures.

- `layertree_insertions.md` — proposed insertions that would add LayerTree as a
  fourth settlement object, with the recomputed bound; adopted into the paper
  on 2026-10-16 and kept as the sourcing record. `model/layertree.ts` holds its
  cost tables.

## Connector Calculus and its audit

- `manuscript.md` — the first manuscript, frozen at baseline `a0a3140` and
  hash-bound by `audit/validate_bundle.py`.
- `manuscript_errata.md` — corrections recorded beside the frozen file rather
  than applied to it.
- `references.bib` — bibliography for the Markdown manuscripts.
  `python -m spiral_ln.paper --input paper/manuscript.md --output output/pdf/connector_calculus.pdf`
  builds the PDF.
- `liquidity_on_trial.md`, `connector_calculus_critique.md` — the adversarial
  audit's papers; its evidence and scripts are under `audit/`, starting from
  `audit/README.md`.
