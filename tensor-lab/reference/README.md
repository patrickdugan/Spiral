# Reference

The paper this lab works from is OpenAI's "An Upper Bound of 9/4 for the Matrix
Multiplication Exponent" (October 2, 2026), published in the `openai/math`
repository under `preprints/Matrix-Multiplication-Nine-Fourths-October-2-2026/`,
with its Lean formalisation under `lean/OAI/LinearAlgebra/MatrixMultiplication/`.

A local copy (`openai_nine_fourths_2026-10-02.pdf`) is used during work but is not
committed (third-party document); fetch it from the source above.
